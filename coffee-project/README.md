# Koppee React

React/Vite recreation of the coffee-shop layout shown in the provided screenshots.

## Run

1. Install Node.js.
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local Vite URL shown in the terminal.

## Notes

- The page is componentized into Hero, About, Services, Promo, Menu, Booking, Testimonials and Footer.
- Navigation uses smooth scrolling.
- Mobile navigation, newsletter forms, booking form state and testimonial dots are functional.
- Images currently use the public Koppee demo image URLs so the design closely matches the screenshots. Internet access is needed for those images.
- The original reference is the free Koppee coffee-shop template by HTML Codex / ThemeWagon.
